## Project Overview
Linqua is a Flutter-based mobile vocabulary learning application that captures foreign words from external applications via OS Share Intents and transforms them into interactive flashcards powered by a Dual-Engine Online/Offline Translation Service, SM-2 Spaced Repetition, Text-to-Speech (TTS), and cognitive mini-games.
